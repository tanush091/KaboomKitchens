Week 10 · HTTP POST

Table Booking with POST

Send a reservation to a server with fetch() using the POST method, and read the server's reply.

Lab & Viva Concept Note: A real POST request requires a backend web server (e.g. Node.js, Express, PHP, Python) connected to a database (e.g. MySQL, MongoDB) to store reservations permanently. Frontend client-side code alone cannot permanently save data. In this demonstration, we transmit our booking payload via Fetch API using method: 'POST' and headers: { 'Content-Type': 'application/json' } to a public test endpoint (jsonplaceholder.typicode.com/posts) to observe the complete request-response cycle and HTTP status codes (e.g., 201 Created).
